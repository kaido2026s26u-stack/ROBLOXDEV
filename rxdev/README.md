# RXDEV v1.0.0

Roblox / Delta向けユーティリティ。AntiAFK、Console OPEN、段階式FastMode、Extreme、描画パフォーマンス計測をまとめています。

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kaido2026s26u-stack/ROBLOXDEV/main/RXDEV.lua"))()
```

従来の `Utilities.lua` URLも同じRXDEVを起動します。再実行すると以前のパネルを終了し、設定と押下中のキーを復元してから置き換えます。古いスタンドアロンの入力制限機能も移行時に終了します。

## 操作

- 上段：OFF → Fast → Advanced → Super → Ultra → 全軽量化OFF。初回取得中も連打で目標段階を変更できます。5回で一周します。
- 黄色：どの段階からでもUltraまでの全軽量化とExtremeを有効化。もう一度押すと全軽量化OFF。取得中の再クリックはキャンセルと全軽量化OFFです。
- AntiAFK：30〜60秒のランダム間隔でF13/F14/F15を送信。ユーザー操作によるスキップはありません。ログの入力検出はAFKタイマー解除の証明ではありません。
- Console：開く操作です。
- STOP ALL / CLOSE：軽量化復元、AntiAFK停止・キー解放、イベント切断、パネル終了。全軽量化OFFだけではAntiAFKは停止しません。

## モジュール構成

起動用 `RXDEV.lua` が共通ローダーをloadstringで読み込み、以降のモジュールも同じローダーを経由します。標準のModuleScript requireではありません。

| ファイル | 役割 |
|---|---|
| `v1.0.0/Loader.lua` | HTTP取得・コンパイル・戻り値検証・キャッシュ・同時取得の共有 |
| `v1.0.0/Manifest.lua` | バージョン、GUI識別名、モジュールの必須メソッド |
| `v1.0.0/App.lua` | 組み立て、Console、ライフサイクル、接続の後始末 |
| `v1.0.0/UI.lua` | 画面生成とドラッグ |
| `v1.0.0/AntiAFK.lua` | キー送信と診断 |
| `v1.0.0/Graphics.lua` | 段階変更、ExtremeのUltra包含、連打、非同期キャンセル |
| `v1.0.0/FastMode.lua` | Fast〜Ultraの適用、追加オブジェクト追跡、復元 |
| `v1.0.0/ExtremelyFastMode.lua` | 3D GUI・ViewportFrame非表示、遠方装飾候補の非表示 |
| `v1.0.0/PerformanceMeter.lua` | FPS、Render CPU/GPU時間、Draw/Tri、ゲージ |

読み込むだけでは各機能は動きません。App.start、各機能のstartが適用を開始します。FastとExtremeは最初に使用したときに取得し、以後は同じ起動内のキャッシュを使用します。失敗した取得はキャッシュせず、再試行できます。同一モジュールの同時取得は1リクエストにまとめます。getgenvやファイル書き込みに依存せず、キャッシュは起動ごとに閉じます。

## 適用・負荷・復元

Fastの探索は最大64オブジェクト・約2msずつに分割します。Extremeの遠方判定はカメラ移動に応じて分割実行します。Statsの取得は最大5Hz、計測表示は2Hz、状態表示は4Hzです。分割による実機FPS向上を保証するものではありません。

復元は変更前の値を保存し、自分が設定した値のままの場合に戻します。途中でゲームや別スクリプトが変更した値は可能な範囲で保持します。同じ値を別スクリプトが書いた場合は区別できません。

Extremeの遠方非表示は180 studs超で適用、150 studs未満で復帰します。Anchoredかつ非衝突・非接触で、キャラクター・Tool・検出できる操作対象を除く装飾候補に限定します。候補判定なので必要なゲーム表示を含む可能性があります。物理オブジェクトの削除は行いません。

ゲージはCPU/GPU描画時間の大きい方を60 FPSのフレーム予算と比較します。端末全体の使用率や余力の直接測定ではありません。取得できない値はN/Aです。

## 更新手順

1. 新しい版のディレクトリを作り、Manifestのバージョンと必要なインターフェースを更新します。
2. 構文・連打・初回取得・失敗後の再試行・移行・全解除・計測のテストを実行します。
3. モジュール一式を同一コミットとして保存します。
4. RXDEV.luaのBASEを、そのコミットSHAとバージョンディレクトリに固定します。バージョン照合も更新します。
5. RXDEV.luaと互換用Utilities.luaを同時に更新し、Raw内容を確認します。

mainのモジュールURLを混ぜて参照しないでください。リリース単位のコミット固定により更新途中の混在を防ぎます。旧ルート直下のFastMode.lua等は互換のため残していますが、RXDEVは上記の版別モジュールを使用します。

v1.0.0の検証はヘッドレスLuauランタイムによるものです。RobloxのGPU描画、Deltaの実入力、ネットワーク上のAFK解除は実機で別途確認する必要があります。
